# xLSTM Chat

A high-performance chat GUI and API for [xLSTM](https://arxiv.org/abs/2405.04517) language models.

<p align="center">
  <strong>🖥️ Web Chat</strong> · <strong>⚡ Streaming API</strong> · <strong>🐳 Docker Ready</strong> · <strong>📄 Auto-Docs</strong>
</p>

## Features

- **Modern Chat Interface** — Clean, responsive web UI with real-time streaming
- **Dual Model Support** — Switch between xLSTM Small (NeurIPS) and xLSTM Large (7B)
- **High-Performance Streaming** — WebSocket + SSE for token-by-token generation
- **Complete REST API** — Full CRUD for models, chat, and configuration
- **Auto-Documentation** — Swagger UI + ReDoc generated from code; MkDocs for guides
- **Docker Deployment** — CPU and GPU containers with Docker Compose
- **Future-Ready** — Extension points for Vision-LSTM support

## Quick Start

### Install & Run

```bash
# From the repository root
pip install -e .
pip install -r chat/requirements.txt

# Start the server
python -m chat
```

Open [http://localhost:8000](http://localhost:8000) for the chat interface.

### Docker

```bash
cd chat

# CPU mode
docker compose up --build

# GPU mode
docker compose --profile gpu up --build
```

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/v1/chat` | Chat completion (batch or streaming) |
| `WS` | `/api/v1/chat/ws` | WebSocket streaming chat |
| `GET` | `/api/v1/models` | List available models |
| `GET` | `/api/v1/models/current` | Current model info |
| `POST` | `/api/v1/models/load` | Load a model variant |
| `POST` | `/api/v1/models/unload` | Unload current model |
| `GET` | `/api/v1/health` | Health check |
| `GET` | `/api/v1/config/generation` | Get generation config |
| `PATCH` | `/api/v1/config/generation` | Update generation config |

### Interactive API Docs

- **Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)

### Example: Chat via cURL

```bash
# Load a model
curl -X POST http://localhost:8000/api/v1/models/load \
  -H "Content-Type: application/json" \
  -d '{"variant": "small"}'

# Send a chat message
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "Hello!"}],
    "max_new_tokens": 100
  }'
```

### Example: WebSocket (JavaScript)

```javascript
const ws = new WebSocket("ws://localhost:8000/api/v1/chat/ws");

ws.onopen = () => {
    ws.send(JSON.stringify({
        messages: [{ role: "user", content: "Tell me about xLSTM" }],
        max_new_tokens: 200,
        temperature: 0.7,
    }));
};

ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.done) console.log("\n[Done]");
    else process.stdout.write(data.token);
};
```

## Configuration

All settings via environment variables:

| Variable | Default | Description |
|----------|---------|-------------|
| `XLSTM_CHAT_PORT` | `8000` | Server port |
| `XLSTM_CHAT_MODEL_VARIANT` | `small` | Model: `small` or `large` |
| `XLSTM_CHAT_DEVICE` | `auto` | Device: `cpu`, `cuda`, `auto` |
| `XLSTM_CHAT_CHECKPOINT_PATH` | — | Checkpoint path for large model |
| `XLSTM_CHAT_MAX_NEW_TOKENS` | `256` | Default max generation tokens |
| `XLSTM_CHAT_TEMPERATURE` | `0.7` | Default sampling temperature |

Or via CLI:

```bash
python -m chat --port 8080 --variant small --device cpu
```

## Model Variants

| Variant | Parameters | Device | Description |
|---------|-----------|--------|-------------|
| `small` | ~8.5M | CPU/GPU | xLSTM NeurIPS architecture, fast inference |
| `large` | ~7B | GPU | xLSTM Large 7B, high-quality generation |
| `vision` | — | — | *Planned*: Vision-LSTM backbone |

## Project Structure

```
chat/
├── api/                    # FastAPI routes and schemas
│   ├── app.py              # Application factory
│   ├── schemas.py          # Pydantic models → auto-generates OpenAPI docs
│   └── routes/             # Endpoint modules
├── core/                   # Model management and inference
│   ├── config.py           # Configuration with env var support
│   ├── model_manager.py    # Model loading/switching
│   └── inference.py        # Generation engine with streaming
├── frontend/               # Vanilla HTML/CSS/JS chat interface
├── tests/                  # Pytest test suite
├── Dockerfile              # Multi-stage container build
├── docker-compose.yml      # CPU + GPU deployment
└── requirements.txt        # Python dependencies
```

cd docs && mkdocs serve
